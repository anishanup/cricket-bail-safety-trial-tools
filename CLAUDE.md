# Writing rules for this repository

Readers are cricket people: league officials, umpires, club volunteers, and
governing bodies. Most are not native English speakers.

Write in plain, simple English.

- Short sentences. One idea per sentence.
- Common words. If a word needs a dictionary, change it.
- No idioms. Write "the collar is wider than the stump", not "stands proud of".
  Write "compare this with", not "for scale".
- No filler. Cut any phrase that adds no information.
- No em dashes. Use a comma, a full stop, a colon or brackets instead.
  Write "the collar is wider, so a ball can hit it" not "the collar is wider so
  a ball can hit it". Use only normal punctuation: full stop, comma, colon,
  semicolon, question mark, brackets, hyphen in hyphenated words.
- Say the number, not a phrase about the number. "0.03%" beats "one part in
  three thousand".
- Give the worst case first, then the normal case. Never let a reader find a
  worse number than the one published.

Reports are generated by the scripts in src/scripts, not written by hand.
To change wording in a report, change the string in the script and regenerate.
The only thing read back from a generated report is the hand-checked video
times in the MiLC highlights table.
